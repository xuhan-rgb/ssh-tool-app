# SSH Tool App

用 Android 手机连接电脑上的 Codex，以文字聊天的方式查看对话、发送消息、选择方案和确认操作。

你可以继续电脑上已经打开的对话，也可以从手机选择目录，新建对话。电脑负责处理任务，手机用于查看和操作。

下方界面使用代码模拟，未使用截图。电脑名称、账号、地址、目录、对话内容和状态数值均为虚构示例，实际布局以应用为准。

## 1. 安装到手机

将 `app-release.apk` 安装包传到 Android 手机上，打开文件并按系统提示安装。如果系统询问是否允许安装，请允许本次安装。

更新应用时，直接安装新版安装包即可。为了保留已保存的连接，不要先卸载旧版。

## 2. 准备电脑

使用 Codex 前，请确认：

- 电脑已安装 Codex，能够登录并正常聊天。
- 电脑已开启 SSH，手机能够连接到它。
- 你知道电脑的地址、SSH 端口、登录用户名和密码。

目前，应用内的 Codex 环境准备适用于 Linux 电脑。电脑需要保持开机，并且手机能够访问它的网络地址。

## 3. 添加电脑连接

1. 打开应用，首页选择 **Codex**。
2. 点击 **新建连接**。
3. 填写连接名称、电脑地址、端口、用户名和密码。SSH 端口通常是 `22`，以电脑的实际设置为准。
4. 保存后，点击这台电脑进行连接。

**首页示意**：点击电脑卡片连接，卡片右侧的菜单用于打开环境配置等操作。

```text
┌──────────────────────────────────────────┐
│  >_ SSH 终端                通知  配色   │
│                                          │
│       [ Codex ✓ ]   [ Claude ]           │
│                                          │
│  我的电脑                  已连接  ⋮     │
│  demo@192.0.2.10:22                      │
│  密码                                    │
│                                          │
│                         [ 新建连接 ]     │
└──────────────────────────────────────────┘
```

可以保存多台电脑。使用时注意选择对应的连接；不同电脑、不同登录账号的对话不会混在一起。

## 4. 首次连接：准备环境

首次连接时，如果应用提示环境尚未就绪，按页面提示完成准备。以后也可以从首页这台电脑的 **更多操作 → Codex 环境配置** 进入。

已经能够正常聊天的电脑，先点击 **一键准备**。如果页面提示缺少工具、尚未登录或版本需要更新，再使用对应按钮：

- **安装缺失依赖**：安装手机连接所需的电脑端工具，按提示操作。
- **登录 Codex**：打开页面提供的授权网址，输入验证码，完成登录。
- **更新 Codex**：按提示更新电脑上的 Codex。
- **一键准备**：完成手机与电脑之间的对话连接准备。

看到 **环境已就绪** 后，返回对话列表开始使用。已经就绪的电脑不需要每次重复准备。

如果电脑上使用了网络代理，应用沿用电脑的网络设置，不需要在手机应用中再填写代理。

## 5. 继续电脑上的对话

在电脑终端进入你的项目目录，再启动 Codex：

```bash
cd ~/my-project
codex
```

将 `~/my-project` 换成你自己的项目目录，然后在电脑上开始对话。

在手机上：

1. 连接同一台电脑，并使用同一个登录账号。
2. 在 **远程打开** 列表中找到对应的对话。
3. 点击对话右侧的 **查看对话** 图标，阅读内容或发送消息。

**对话列表示意**：在“远程打开”中找到对话，点击该条目的查看按钮。

```text
┌──────────────────────────────────────────┐
│  选择 Codex 对话       新建对话  聊天    │
│ CPU 18% · GPU 35% · 显存 2/8G  额度 75% │
│         [ 对话 ]   [ 收藏 ]              │
│  [远程打开]  新回复  历史  筛选          │
│                                          │
│  ~/projects/demo                         │
│    整理项目说明                          │
│    帮我补充使用步骤……    [ 查看对话 ]    │
└──────────────────────────────────────────┘
```

手机和电脑可以使用同一条对话。手机发送的消息会交给这条对话继续处理；返回列表后，也可以再次打开查看结果。

## 6. 从手机新建对话

1. 进入电脑的对话列表，点击顶部的 **新建对话**。
2. 选择这次任务要使用的目录。
3. 进入聊天页，输入并发送第一条消息。

选择目录时：

- 点击箭头展开下一级目录，点击目录名称选中它。
- 可以返回上一级、回到主目录，或手动输入完整路径。
- 隐藏目录默认不显示，可在右上角 **目录显示选项** 中开启。
- 常用目录可以收藏；开启 **只显示收藏目录** 后，可以更快找到它们。
- 在 **收藏目录** 中可以添加、编辑和取消收藏。

**目录选择示意**：箭头展开目录，目录名称用于选中；选好后点击底部按钮。右上角菜单可以开启“只显示收藏目录”。

```text
┌──────────────────────────────────────────┐
│  ← 新建对话              ⋮  输入路径     │
│                                          │
│  主目录  上级目录  ☆收藏  收藏目录       │
│  /home/demo/projects/app                 │
│                                          │
│  ▾ projects                              │
│      ▾ app                  ← 已选中     │
│          ▸ src                           │
│          ▸ docs                          │
│      ▸ tools                             │
│                                          │
│  □ 收藏新对话                            │
│         [ 在此目录开始聊天 ]             │
└──────────────────────────────────────────┘
```

收藏目录用于方便下次选择；列表中的目录筛选只影响显示哪些对话。两者分别设置，选择一个目录不会自动将它收藏。

## 7. 选择方案与确认操作

当 Codex 提出选择题时，手机对话页面会显示问题和选项：

1. 点击你想选择的选项。
2. 如果有多个问题，逐题填写或选择。
3. 全部答完后，点击 **提交**。

**触屏选择示意**（问题和答案为示例）：直接点选答案，再点击“提交”。多个问题会依次显示，可以在问题区域上下滑动。

```text
┌──────────────────────────────────────────┐
│  选择哪种实现方式？                      │
│                                          │
│  ○ NumPy 实现                            │
│    需要安装 NumPy                        │
│                                          │
│  ● 纯 Python 实现                        │
│    无需第三方依赖                        │
│                                          │
│  ○ 其他                                  │
│                                          │
│                         [ 提交 ]         │
└──────────────────────────────────────────┘
```

如果提供了 **其他** 选项，也可以输入自己的答案。提交后，Codex 会根据答案继续对话；如果你已经在电脑上回答，手机上的问题会同步收起。

当 Codex 请求确认命令执行或文件修改时，先阅读操作内容，再选择允许或拒绝。提交失败时，按页面提示重试。

如果希望 Codex 先提出方案供你选择，可以在电脑端按 `Shift + Tab` 切到 Plan 模式，再说明你的需求。

## 8. 查找和管理对话

- **远程打开**：查看电脑上仍打开的对话。
- **新回复**：查看尚未阅读的新回复。
- **历史**：查看之前的对话，可按目录或时间筛选。
- **收藏**：查看收藏的对话；长按一条对话可以收藏或取消收藏。

在“远程打开／新回复／历史”右侧，点击 **筛选图标**，只显示当前列表中正在运行或有未读回复的对话；再次点击恢复。

查看对话时，可以切换显示方式：

- **只看对话**：主要查看聊天内容。
- **终端视图**：同时查看执行过程的摘要。
- **完整日志**：查看更详细的过程记录。

在对话操作菜单中，还可以更改模型或清空上下文。更改模型后，下次发送消息时生效；清空上下文会开始新的对话，旧记录仍保留。

## 9. 查看电脑状态和 Codex 额度

对话列表顶部用一行显示电脑状态和额度：

```text
CPU 18% · GPU 35% · 显存 2/8G    额度 75%
```

- **CPU**：电脑当前的 CPU 利用率。
- **GPU**：显卡当前的利用率。
- **显存**：已用量 / 总量，顶部使用简短单位。
- **额度**：当前 Codex 账号最短周期的剩余百分比。例如 `75%` 表示还剩 75%，不是已使用 75%。

点击 **CPU/GPU 区域**，查看核心数、每张显卡的利用率和精确显存用量。多张显卡会在顶部显示数量，分别在详情中查看。

点击 **额度**，查看所有返回的额度周期、剩余百分比和重置时间，也可以手动刷新。电脑无需额外安装额度查询命令。

页面前台显示时，电脑状态每 15 秒更新，额度每分钟更新。无法读取的硬件数值显示为“未知”或“暂不可用”；额度未读取成功时显示 `额度 —`，不会当作 0%。

## 10. 使用 Claude

电脑已安装并登录 Claude 时，可以在首页切换到 **Claude**，再选择电脑连接，查看或新建对话。

Claude 首次授权、目录信任和部分操作确认需要在电脑终端完成。如果手机提示需要终端处理，请回到电脑完成提示的操作。

## 常见问题

**连接不上电脑怎么办？**

检查电脑是否开机、SSH 是否开启，以及地址、端口、用户名和密码是否正确。手机需要能够访问该地址；只在家中网络可访问的地址，离开该网络后可能无法连接。

**手机找不到电脑上的对话怎么办？**

确认连接的是同一台电脑、同一个登录账号，再检查列表的目录和时间筛选。可以返回列表重新打开；首次使用时，按环境页面提示完成准备。

**电脑能聊天，手机却发送失败怎么办？**

查看页面的错误提示，并检查电脑网络和 Codex 登录状态。需要时进入 **Codex 环境配置** 重新检查环境。如果电脑提示版本或功能设置不匹配，先按电脑端提示处理，再重试。

**退出电脑终端后，手机为什么还显示“远程打开”？**

打开状态同步可能有延迟，稍后刷新即可。关闭终端不会删除对话历史。

**返回手机首页后，任务会停止吗？**

手机发起的任务会继续在电脑上处理。可以稍后重新打开对话查看结果；电脑仍需保持开机和网络可用。

**GPU 或显存为什么显示未知？**

部分电脑的显卡驱动没有提供可读取的利用率或显存信息。这表示应用暂时读不到数值，不表示显卡没有工作。点击电脑状态查看详情。

**额度为什么没有数值？**

点击 **额度** 查看提示并刷新，确认电脑上的 Codex 已登录且网络正常。API Key 或第三方服务账号可能不提供 Codex 额度信息。

**连接密码保存在哪里？**

连接信息保存在安装应用的设备上。请保护好设备，避免将保存了密码的应用数据分享给他人。
