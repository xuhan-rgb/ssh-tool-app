# 手机端 Codex 对话生命周期与新建入口

用户已授权按照讨论方案实现，并明确新建时优先展示收藏目录，同时可以选择其他目录。

## 行为

- 新建页面默认选择已收藏的当前目录，否则选择收藏目录；无收藏时回退到当前目录。收藏目录直接可选，其他目录通过目录浏览器选择，确认后自动收藏。
- 文字聊天为默认方式，进入聊天页面只建立草稿；首条消息发送后启动远程 app-server。终端方式保留在更多选项。
- 每条发送保留独立 jobId、进度事件和完成结果，同一会话的后续消息交给同一个常驻 app-server。页面退出或 SSH 断开不关闭远程会话。
- 回答完成后远程会话继续打开，状态为等待消息；手机提供关闭空闲自有会话的操作，执行期间禁止关闭。进程退出后保留历史，下次发送恢复原 threadId。
- 对话入口为远程打开、新回复、历史。远程打开默认展示，允许非收藏目录，收藏目录优先，不显示历史分页及底部动作栏。自有空闲会话可直接进入聊天。
- 新回复依赖完成通知或上次查看时间，不将首次导入历史全部当作未读，也不使用 24 小时完成窗口。运行状态保留在每条对话上。

## 实现约束

远程真实 writer 锁用于打开状态；自有会话元数据仅用于消息路由和关闭权限。每轮 job 的完成状态与常驻会话存活状态分离。启动请求通过文件锁串行化，重复 jobId 不重复执行。关闭仅针对本软件管理的会话。

## 验证

使用隔离 tmux 和模拟 app-server 验证重复请求、同进程多轮、断线跟随、关闭、退出及外部锁；Flutter 组件测试覆盖目录选择、列表默认入口、未读与已读、自有空闲会话接入、草稿和关闭状态。实际 Codex 空会话验证空闲持锁及退出释放。检查收敛后构建并安装 Android 包；本次新增页面不进行未经新授权的现场截图检查。
